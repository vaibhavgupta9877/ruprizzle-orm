# ruprizzle-d1

Cloudflare D1 edge database adapter for the [ruprizzle](https://github.com/vaibhavgupta9877/ruprizzle-orm) ORM.

## Overview

`ruprizzle-d1` provides integration with Cloudflare D1 databases, supporting:
- Cloudflare D1 REST API queries.
- Cloudflare Workers WASM execution.
- Seamless compatibility with `ruprizzle::Executor` query builders.
