# ruprizzle-neon

Neon serverless PostgreSQL database adapter for the [ruprizzle](https://github.com/vaibhavgupta9877/ruprizzle-orm) ORM.

## Overview

`ruprizzle-neon` provides seamless integration with Neon Serverless Postgres, supporting:
- WebSocket connection multiplexing.
- HTTP query transport.
- Seamless compatibility with `ruprizzle::Executor` query builders.
