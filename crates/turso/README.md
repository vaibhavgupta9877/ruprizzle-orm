# ruprizzle-turso

Turso and libSQL edge database adapter for the [ruprizzle](https://github.com/vaibhavgupta9877/ruprizzle-orm) ORM.

## Overview

`ruprizzle-turso` provides seamless integration with Turso and libSQL databases, supporting:
- Local embedded SQLite replicas with zero-latency reads.
- Background and on-demand synchronization over HTTP / WebSocket.
- Seamless compatibility with `ruprizzle::Executor` query builders.
