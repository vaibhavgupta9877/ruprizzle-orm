# Project planning archive

This folder holds the plans, audits and roadmaps written while ruprizzle was being
built. They are kept for their reasoning, not as a current status report:

- Status lines, checkboxes and version numbers in these files reflect the date each
  one was written. Several predate the 1.x releases and name versions that were never
  published (for example `0.1.2-beta.1` and `1.0.0`; see `RELEASES.md`).
- For what has shipped, read [`CHANGELOG.md`](../CHANGELOG.md) and
  [`RELEASES.md`](../RELEASES.md). For the registry state, run
  `scripts/check-release-state.sh`.
- The documents in `docs/` are the user-facing source of truth.
